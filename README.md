# Proyecto IPC - Estudio de cartas náuticas del estrecho de Gibraltar

## Integrantes
- Gabriela Rego Jamhour
- Rafael Alonso Pellizzari

## Tecnologías
- Java 21
- JavaFX
- SceneBuilder
- NetBeans
- SQLite (via Navegacion.jar)

## Funcionalidades
- Registro/Inicio de sesión/Perfil
- Herramientas de dibujo: punto, línea, arco
- Transportador, regla, medición de distancias
- Zoom + scroll
- Sistema de problemas tipo examen
- Historial de sesiones

## Cómo ejecutar
1. Clonar el repositorio
2. Abrir en NetBeans
3. Añadir JavaFX SDK al proyecto
4. Ejecutar `Main`
